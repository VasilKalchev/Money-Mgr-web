Connect Google Drive

This app signs in with your own Google API project, so no credentials are shared with anyone. Sync downloads the newest MM*.mmbak backup, merges it with the database here and writes the result back to that same file, so you can restore it in Money Manager. It never touches other files. {% if connected %}Currently connected. Saving below signs in again.{% endif %}

1. Create a Google Cloud project and OAuth client

  1. Open the Google Cloud Console and create a project (any name), or pick one you already have.
  2. Enable the API: Google Drive API → Enable.
  3. Open Google Auth Platform and configure the consent screen: app name and your email, Audience External. Under Data access, add the scope .../auth/drive (or .../auth/drive.readonly if you'll turn off writing below).
  4. Under Audience, click Publish app (it stays unverified, which is fine for personal use). If you leave it in Testing, add your Google account as a test user, but Google then expires the sign-in every 7 days.
  5. Under Clients, Create client, application type Desktop app. Copy the Client ID and Client secret. An existing Desktop-app client (for example the one rclone uses) works too.
